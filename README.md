# 부산 생태탐사대 · 3주제 개정판

초등학교 4학년이 부산의 지역문제와 생태계 문제를 함께 조사하는 웹앱입니다. 사회 ‘지역문제 해결’, 과학 ‘생물과 환경’, 국어 ‘제안하는 글쓰기’ 통합 프로젝트에서 사용합니다.

**세 주제 × 읽기 자료 8개 = 총 24개 자료**를 18개 원문에서 재구성했습니다. 여러 모둠이 같은 주제를 고르고도 제안할 대상과 해결 방법을 달리할 수 있게 보강했습니다.

## 태블릿 글씨 크기 개정 (2026.10.30)

기본 읽기 본문은 24px, 자료 목록·질문·입력 칸은 20~21px, 주요 버튼은 18~20px로 키웠습니다. 출처·안내 글씨도 16~18px로 확대했습니다. 상단 ‘가+’를 누르면 읽기 본문이 28px로 더 커집니다. 작은 화면에서는 메뉴와 기록 화면을 줄 바꿈하고, 본문을 줄이거나 자르지 않고 스크롤하여 읽습니다.

## 세 가지 주제

| 주제 | 함께 볼 지역의 생활 | 함께 볼 생태계 |
|---|---|---|
| 온천천 두꺼비의 이동길 | 주민의 길 이용과 구청의 관리 | 먹이·이동길·알을 낳는 곳 |
| 을숙도 철새의 쉼터 | 시민의 공원 이용과 관리 | 철새의 먹이와 쉴 곳 |
| 부산 바다의 쓰레기 | 바다의 이용과 쓰레기 관리 | 생물의 몸과 살아가는 곳 |

## 사용 흐름

1. 홈에서 관심 있는 주제를 엽니다.
2. 8개 자료 목록에서 글을 선택해 읽습니다. 지역 기사·생물 설명·조사 결과·지역의 노력을 함께 봅니다.
3. ‘자료에서 찾기’와 ‘함께 생각하기’ 질문을 따라 사실과 자신의 생각을 구분합니다.
4. 생각의 근거가 되는 자료를 바구니에 담습니다.
5. 생태계 연결과 사람들에게 필요한 것을 살펴봅니다.
6. 탐구 노트에 문제, 생물에게 생기는 일, 주민에게 필요한 것, 제안할 대상, 더 궁금한 점을 정리합니다.
7. 노트를 내려받고 제안하는 글·영상·만화·포스터로 이어 갑니다.

완성된 제안문이나 질문의 답은 자동으로 채우지 않습니다. 모둠원끼리 자료를 나누어 읽고 설명하며 근거를 모으는 방식으로도 활용할 수 있습니다.

## 실행과 GitHub·Vercel 배포

압축을 풀고 index.html을 열면 실행됩니다. 사진과 읽기 자료는 모두 포함되어 있어 핵심 기능에 외부 API·CDN이 필요하지 않습니다. 외부 원문을 열 때에는 인터넷이 필요합니다.

1. 압축 안의 index.html, styles.css, app.js, data.js, vercel.json과 assets 폴더 등을 GitHub 저장소 최상단에 올립니다. ZIP 자체를 올리지 않습니다.
2. 기존 앱을 수정한다면 기존 저장소에서 해당 파일들을 덮어 올립니다.
3. Vercel에서 저장소를 Import합니다. Framework는 **Other**, Root Directory는 **최상단(./)**입니다.
4. 별도의 빌드·설치 명령과 환경변수 없이 배포합니다. 정적 배포 설정은 vercel.json에 포함되어 있습니다.
5. 배포된 주소를 학생에게 공유합니다.

Firebase·API 키·Google 로그인·Node 패키지 설치는 필요하지 않습니다. 기존 GitHub와 연결된 Vercel 프로젝트라면 수정 파일을 올린 뒤 다시 배포됩니다.

공식 설정: [Vercel 프로젝트 설정](https://vercel.com/docs/project-configuration).

## 기록

- 같은 주소에 들어가도 각 브라우저에 독립 저장됩니다. 실시간 공동편집·교사 자동 수합은 없습니다.
- 대표 기기에 모둠 토의를 기록하거나 개인 노트를 내려받아 모아 활용할 수 있습니다.
- PNG 이미지, TXT, 인쇄/PDF, JSON 백업을 지원합니다. PDF는 인쇄 창에서 ‘PDF로 저장’을 선택합니다.
- 다른 기기에서는 JSON 기록 파일을 불러와 이어서 사용할 수 있습니다.
- 브라우저 저장 공간을 삭제하면 기록이 없어질 수 있으므로 필요한 기록 파일을 내려받아 보관하세요.
- 이전판의 기록도 유지합니다. 홈에서 제외한 주제는 새 탐색 목록에는 나타나지 않지만 기존 바구니에서 다시 읽거나 내보낼 수 있습니다.
