# 부산 생태탐사대

초등학교 4학년 사회·과학·국어 통합 프로젝트에서 부산의 생태 문제를 발견하고 조사하는 웹앱입니다.

**실제 자료 읽기 → 생태계와 연결하기 → 여러 입장 생각하기 → 탐구 문제 선택**의 흐름으로 사용합니다. 완성된 제안문이나 캠페인을 대신 만들어 주지 않으며, 학생들이 근거를 골라 자신의 문제와 질문을 정리하도록 구성했습니다.

## 실행

압축을 풀고 `index.html`을 열면 실행됩니다. 사진과 읽기 자료를 포함한 핵심 기능은 외부 API·CDN 없이 작동합니다. 출처 원문을 열 때에는 인터넷이 필요합니다. 기기 간 기록을 옮길 때는 바구니의 기록 파일 저장·불러오기를 이용하세요. PC의 파일 주소에서 만든 기록과 배포한 웹 주소의 기록은 별개입니다.

## GitHub → Vercel 배포

1. ZIP 압축을 풉니다.
2. GitHub에서 새 저장소를 만듭니다. 예시 이름: `busan-eco-explorer`.
3. **압축 안의 `index.html`, `styles.css`, `app.js`, `data.js`, `vercel.json`과 `assets` 폴더 등을 저장소 최상단에 올립니다.** ZIP 파일 자체나 바깥 폴더 하나만 올리지 않습니다.
4. Vercel에서 Add New → Project → 해당 GitHub 저장소 Import를 선택합니다.
5. Framework Preset은 **Other**, Root Directory는 **저장소 최상단(`./`)**을 사용합니다.
6. 빌드·설치 명령을 따로 입력하지 않습니다. `vercel.json`에 정적 파일 제공 설정이 들어 있습니다. Output Directory를 직접 지정하는 경우 `.`을 사용합니다.
7. 환경변수를 추가하지 않고 Deploy를 누릅니다.
8. 배포 완료 후 받은 `.vercel.app` 주소를 학생에게 공유합니다.

Firebase, API 키, Google 로그인, Node 패키지 설치는 필요하지 않습니다. 이후 GitHub 파일을 수정하면 연결된 Vercel 프로젝트가 다시 배포됩니다.

공식 설정 참고: [Vercel 프로젝트 설정](https://vercel.com/docs/project-configuration).

## 기능

- 하천·습지·바다·도시 필터와 장소·생물 검색
- 주제별 실제 사진, 읽기 자료 3개, 날짜·발행기관·원문 링크
- 통계 그래프와 표, 관계 그림, 유리창 무늬 표시 체험
- 과학 개념과 연결하는 질문, 펼쳐 읽는 도움말, 낱말 설명
- 여러 사람과 생물의 입장을 생각하는 카드: 실제 인터뷰로 오인하지 않도록 표시
- 문제 후보·근거 담기, 두 주제 비교, 탐구 주제 선택
- 발견한 문제·궁금한 점·근거 메모, 브라우저 자동 저장
- PNG 이미지, TXT, 인쇄/PDF 저장, JSON 백업·복원
- 글씨 크게 보기, 키보드 접근, 태블릿·스마트폰 반응형 배치

## 기록의 범위

같은 주소로 접속해도 **각 기기·브라우저에서 독립적으로 사용하는 앱**입니다. 실시간 모둠 공동편집과 교사 화면 자동 수합 기능은 없습니다. 학생 기록은 서버로 보내지지 않으며, 브라우저 저장 공간을 삭제하면 기록도 없어질 수 있습니다. 내려받은 JSON 파일을 보관하면 다른 기기에서도 이어서 사용할 수 있습니다.

모둠 대표 기기에서 토의 결과를 정리하거나, 개인별로 조사한 뒤 내려받은 노트를 모아 활용하세요. PNG·TXT·PDF에는 선택한 근거의 출처가 함께 들어갑니다. PDF는 인쇄 창의 ‘PDF로 저장’을 선택합니다.

## 5차시 활용 예

1. 자료를 읽고 문제 후보와 근거를 담습니다.
2. 생태계 영향과 여러 입장을 살피고 추가 조사·해결 방안 비교를 합니다.
3. 학생마다 문제·제안·까닭·실행 방법을 담아 제안하는 글을 씁니다.
4. 모둠별로 짧은 영상·4컷 만화·포스터 중 하나를 만듭니다.
5. 제안회를 열어 질문·수정을 거치고 실제 참여 대상에게 전달합니다.

## 자료 수정

`data.js`의 `sources`에 발행기관·원문·날짜가, `cases`에 학생용 설명과 질문이 있습니다. 원문을 확인한 후 함께 수정하세요. 주제·근거의 `id`는 저장된 기록과 연결되므로 기존 ID를 다른 주제에 재사용하지 않습니다.

**원문 최종 확인: 2026년 10월 29일.** 이 앱은 최신 소식을 자동 수집하거나 실시간 수질을 표시하지 않습니다. 날짜가 오래된 자료는 당시 사례로 읽고, 과거 계획을 현재 완료된 사업으로 해석하지 않도록 표시했습니다.

출처는 [SOURCES.md](SOURCES.md), 사진 출처와 이용조건은 [ASSET_CREDITS.md](ASSET_CREDITS.md)를 참고하세요. 사진이 다른 장소의 개체 참고 사진인지, 실제 장소 사진인지, 사고 현장 사진인지도 구분했습니다.
